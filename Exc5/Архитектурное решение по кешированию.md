# Архитектурное решение по кешированию

## Раздел 1: Мотивация

Внедрение кеширования в систему MES направлено на улучшение скорости работы, что удовлетворит требования операторов и повысит качество обслуживания клиентов за счет ускорения выполнения заказов. Кеширование решает следующие проблемы:

- Улучшение времени отклика интерфейса
- Уменьшение нагрузки на сервер и базу данных

### Элементы системы для кеширования:

- **Данные о заказах:** для ускорения отображения и обработки.
- **Информационные панели и дашборды:** для снижения времени загрузки.

## Раздел 2: Предлагаемое решение

### Тип кеширования:

- **Серверное кеширование** выбрано в качестве основного подхода, поскольку оно позволяет управлять большим объемом данных и обеспечивает единую точку контроля.

### Паттерн кеширования:

- **Cache-Aside Pattern:**
  - **Почему выбран:** Позволяет данным попадать в кеш только по мере необходимости.
  - **Почему другие паттерны не подходят:**
    - **Write-Through:** Приводит к дополнительной нагрузке на кеш при каждой записи, что может замедлить работу.
    - **Refresh-Ahead:** Потенциально загружает лишние данные, которые могут не понадобиться, и требует более сложной настройки.

### Стратегия инвалидации кеша:

- **Инвалидация по времени (Time-based):** Кеш автоматически обновляется через заданный промежуток времени. Это подходит для MES, где часто меняющиеся данные нуждаются в актуальности.
  - **Преимущества:** Обеспечивает регулярное обновление данных без чрезмерных нагрузок на серверные ресурсы.
  - **Недостатки других методов:**
    - **По ключу:** Требует управления каждой записью, что может усложнить систему.
    - **Программная инвалидация:** Сложно реализуется и затрудняет поддержку.

### Сравнительный анализ стратегий

| Стратегия                      | Преимущества                                    | Недостатки                           |
|-------------------------------|-------------------------------------------------|--------------------------------------|
| Временная (Time-based)        | Обеспечивает актуальность, простота реализации  | Может увеличить нагрузку при кратких сроках |
| По ключу (Key-based)          | Контроль за конкретными данными                 | Сложность управления                 |
| Программная (Programmatic)    | Максимальная точность                           | Высокая сложность реализации         |
